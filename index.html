Neler Yapıyoruz?

Her gün yeni bir şey deniyor, paylaşıyor ve birbirimizden öğreniyoruz.

  1. 01

    Öğreniyoruz

    // learn
    • Ders çalışıyor, blog okuyup yazıyoruz.
    • Discord üzerinden pair programming yapıyoruz.
    • Linux dağıtımlarını günlük olarak kullanıyoruz.
  2. 02

    Üretiyoruz

    // build
    • Kendi mobil & web uygulamalarımızı yazıyoruz.
    • Git & GitHub ile kod versiyonluyoruz.
    • Hedef odaklı projelerimizi sonuna kadar götürüyoruz.
  3. 03

    Paylaşıyoruz

    // share
    • Eğitimler ve yarışmalar düzenliyoruz.
    • YouTube üzerinden online etkinlikler yapıyoruz.
    • Yeni gelenleri ekibe katıp birlikte yetişiyoruz.
  4. 04

    Hayatta Kalıyoruz

    // fuel
    • Goygoyu seviyoruz ama görevimizi de yapıyoruz.
    • Kahvesiz yapamıyoruz; uzun geceleri onunla kapatıyoruz.
    • Uyumuyoruz — kod yazılacaksa o kahve sıcakken yazılır.
